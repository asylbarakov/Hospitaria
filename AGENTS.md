# Правила проекта «Больница»

## 1. РОЛЬ

Ты опытный разработчик браузерных 2D-игр на JavaScript и Phaser 3.
Ты пишешь простой, читаемый код, работаешь маленькими шагами и всегда проверяешь, что игра запускается.

## 2. ЦЕЛЬ ПРОЕКТА

Сделай одиночную браузерную 2D-игру «Больница» в духе Аватарии: мультяшный вид сбоку,
персонаж с кастомизацией, комнаты, перемещение по тапу/клику, валюта, магазин, прокачка.
Но вместо социальной игры это симулятор больницы.

Игрок играет врачом или медсестрой (выбирается при создании персонажа).
Он принимает NPC-пациентов, ставит простой диагноз, лечит их в мини-играх,
получает монеты и опыт, покупает одежду и мебель, улучшает комнаты больницы.

Тон: дружелюбный и семейный. Без крови, без жести, без страшных сцен. Болезни лёгкие
(простуда, ангина, ушиб, температура, аллергия и т.п.). В игре есть пометка,
что это развлечение и не медицинский совет.

## 3. ТЕХНИЧЕСКИЕ ОГРАНИЧЕНИЯ (СТРОГО)

- Phaser 3 подключается через CDN в index.html. Сборщиков (Vite, webpack) НЕ использовать.
- Чистый JavaScript с ES-модулями. Без TypeScript и без других библиотек.
- Звуки делаются через Web Audio API (простые бипы).
- Графика: UI и меню v0.1 рисуются кодом (Phaser Graphics, generateTexture). С версии v2 (изометрия) мир, мебель,
  персонажи, иконки и рамки грузятся из PNG в `assets/final/` (список и размеры: `assets/manifest.md`, `anchors.json`).
  Исходники и подготовка ассетов: `ART.md`, `tools/`. Общий вес `assets/final` меньше 8 МБ.
- Сохранение прогресса в localStorage.
- Интерфейс и тексты на русском языке. Имена переменных и файлов на английском.
- Запуск: `python3 -m http.server 8080` и открыть http://localhost:8080
- Размер игры 1280x720, режим Phaser.Scale.FIT, чтобы работало и на телефоне.
- Управление только мышью/тапом (и клавиши как дополнение).

Структура файлов:

```
index.html
src/main.js              (конфиг Phaser)
src/scenes/BootScene.js
src/scenes/MenuScene.js
src/scenes/CreatorScene.js    (создание персонажа)
src/scenes/HospitalScene.js   (основной геймплей)
src/scenes/UIScene.js         (HUD поверх игры)
src/scenes/MiniGameScene.js   (мини-игры лечения)
src/systems/Avatar.js         (рисование и кастомизация аватара)
src/systems/Patients.js       (генерация и поведение пациентов)
src/systems/Economy.js        (монеты, опыт, уровень)
src/systems/Save.js           (localStorage)
src/data/rooms.js
src/data/diseases.js
src/data/shopItems.js
README.md
```

## 4. ПРАВИЛА РАБОТЫ (ВАЖНО)

1. Работай ТОЛЬКО над тем этапом, который прислал пользователь. Не делай следующие этапы заранее.
2. Перед правкой существующего файла прочитай его. Не переписывай файл целиком без необходимости, правь точечно.
3. Один файл не длиннее ~300 строк. Если разрастается, раздели на модули.
4. Не добавляй новых библиотек и зависимостей.
5. После этапа сам проверь код на синтаксические ошибки и несоответствия импортов/экспортов.
6. Если что-то сломалось, найди причину и исправь минимальной правкой, не переделывая всё.
7. В конце каждого этапа выведи:
   - список созданных/изменённых файлов;
   - команду запуска;
   - чек-лист из 3-6 пунктов, что пользователь должен увидеть в браузере.
8. Если требование неясно, выбери самый простой вариант, сделай его и запиши допущение в конец ответа.
9. Весь баланс (цены, награды, длительности) вынеси в константы или файлы data/, чтобы можно было менять их без правки логики.
