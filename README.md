# Больница

Одиночная браузерная 2D-игра — симулятор больницы в духе Аватарии.
Phaser 3, чистый JavaScript с ES-модулями, вся графика рисуется кодом.

## Запуск

В папке проекта выполните:

```bash
python3 -m http.server 8080
```

И откройте в браузере: <http://localhost:8080>

> Важно: открывать `index.html` напрямую файлом нельзя — браузер заблокирует ES-модули.

## Управление

- Мышь / тап — кнопки и перемещение по больнице: кликните по полу, и персонаж подойдёт.
- Стрелки `←` / `→` или `A` / `D` — ходьба с клавиатуры.
- `Esc` в больнице — вернуться в меню.

## Структура проекта

```
index.html
src/main.js              конфигурация Phaser
src/scenes/BootScene.js  загрузка и запуск меню
src/scenes/MenuScene.js  главное меню
src/scenes/CreatorScene.js   создание персонажа
src/scenes/HospitalScene.js  больница: камера, ходьба, интерфейс
src/systems/Avatar.js    аватар: контейнер, слои, ходьба
src/systems/avatarDrawing.js  рисование слоёв и позы ног
src/systems/roomPainter.js    стены, пол, двери и таблички комнат
src/systems/furniturePainter.js  рисование предметов мебели
src/systems/Save.js      сохранение в localStorage
src/data/avatarOptions.js    варианты внешности
src/data/rooms.js        комнаты, размеры мира и расстановка мебели
src/ui/Button.js         универсальная кнопка
src/ui/Stepper.js        переключатель вариантов
AGENTS.md                постоянные правила проекта
```
