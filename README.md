# Больница

Одиночная браузерная 2D-игра — симулятор больницы в духе Аватарии.
Phaser 3, чистый JavaScript с ES-модулями. UI и меню v0.1 рисуются кодом,
изометрия и персонажи — PNG из `assets/final`.

## Запуск

В папке проекта выполните:

```bash
python3 -m http.server 8080
```

И откройте в браузере: <http://localhost:8080>

> Важно: открывать `index.html` напрямую файлом нельзя — браузер заблокирует ES-модули.

## Проверка с телефона

- В той же Wi-Fi сети: запустите `python3 -m http.server 8080 --bind 0.0.0.0` и откройте на телефоне `http://<IP-компьютера>:8080`.
- Или поднимите временный туннель, например `cloudflared tunnel --url http://localhost:8080`, и откройте выданную ссылку.

## Управление

- Мышь / тап — кнопки и перемещение по больнице: кликните по полу, и персонаж подойдёт.
- Клик по пациенту — отправить его в нужную комнату; игрок идёт следом, затем открывается окно жалоб.
- Стрелки `←` / `→` или `A` / `D` — ходьба с клавиатуры.
- Кнопка «?» внизу справа — подсказка по управлению.
- `Esc` в больнице — пауза; в паузе можно продолжить, выйти в меню или сбросить сохранение.
- Кнопка «Меню» в HUD открывает ту же паузу.
- Кнопка «Об игре» в главном меню показывает памятку: игра создана для развлечения и не является медицинским советом.
- Звуки кликов, монет, успеха, ошибки и нового уровня работают через Web Audio API; при награде появляются частицы.
- В окне пациента кнопка «Начать приём» запускает мини-игру лечения.
- Мини-игра «Осмотр» — кликайте по подсвеченным точкам на пациенте.
- Мини-игра «Градусник» — остановите бегунок в зелёной зоне (3 попытки).
- Мини-игра «Подбор лекарства» — выберите правильное лекарство по симптому.
- Мини-игра «Укол / капельница» — нажмите в момент, когда игла в зелёной зоне.
- Мини-игра «Дыхание» — отпускайте кнопку в зелёной зоне, чтобы дыхание восстановилось.
- Мини-игра «Капли» — ловите падающие капли, нажимая на них.
- Мини-игра «Компресс» — соберите все нужные предметы для компресса.
- «Пропустить» завершает приём со штрафом к репутации.
- «Магазин» — вкладки «Одежда» и «Мебель / улучшения». Купленные вещи применяются сразу.
- «Задания» — три ежедневных задания с наградой монетами.
- «Успехи» — достижения и коллекция болезней; за достижения начисляются монеты.
- Опыт повышает уровень: открываются новые товары и растёт лимит пациентов.

## Больница и этажи

- Больница состоит из двух этажей. Первый этаж — приёмная, кабинет врача, процедурная,
  палата и кафетерий. Второй этаж — лаборатория, аптека, зона отдыха, архив и ординаторская.
- Лифт справа: нажмите на него или воспользуйтесь стрелкой этажа, чтобы перейти на другой этаж.
  Камера плавно переключается между этажами.
- Часть болезней лечится только в комнатах второго этажа: пациент сам идёт к лифту,
  поднимается и ждёт врача в нужном кабинете.
- На втором этаже есть ежедневные бонусы: лаборатория даёт монеты и опыт,
  комната отдыха повышает репутацию.
