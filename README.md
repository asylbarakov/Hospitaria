# Больница

Одиночная браузерная игра: изометрический симулятор больницы в духе Аватарии (версия **v0.2**).
Phaser 3.80.1 и EasyStar 0.4.4 подключаются через CDN, код на чистом JavaScript с ES-модулями.
Графика (мир, персонажи, интерфейс) лежит в `assets/final` (PNG, около 6 МБ), звуки генерирует Web Audio.
Только русский язык, выбора сложности нет.

## Запуск

```bash
python3 -m http.server 8080
```

Откройте <http://localhost:8080>. Открывать `index.html` файлом нельзя: браузер заблокирует ES-модули.
Нужен интернет для загрузки Phaser и EasyStar (без EasyStar маршруты считает запасной BFS).

С телефона: в той же Wi-Fi сети запустите сервер с `--bind 0.0.0.0` и откройте `http://<IP-компьютера>:8080`,
либо поднимите временный туннель (`cloudflared tunnel --url http://localhost:8080`).

Режимы запуска по адресу:

| Адрес | Что открывается |
|---|---|
| `/` | игра v0.2 (меню → создание персонажа → больница) |
| `/?legacy=1` | старая боковая версия v0.1 (см. ниже) |
| `/?debug=1` | тестовая сцена изометрии (сетка, зум, FPS); открывается сразу, минуя главное меню, выход кнопкой «Меню» |

## Управление

- Тап или клик по полу: персонаж идёт к месту (путь строит EasyStar, мебель и стены обходятся).
- Тап по пациенту: пригласить его в нужный кабинет, затем выбрать диагноз и пройти мини-игру.
- Перетаскивание: камера. Колесо мыши или щипок: зум.
- Кнопки HUD: «Строить», «Персонал», «Задания», «Магазин», «Настройки».
- Клавиатура: `B` режим строительства, `R` поворот мебели, `G` сетка, `Esc` выход из режима.
- Обучение из шести шагов показывается один раз, повторить его можно в настройках.

## Что есть в игре

- 9 кабинетов, 3 открыты сразу, остальные открываются за монеты и кристаллы по уровню.
- Пациенты со своими болезнями идут по маршруту: вход, регистратура, ожидание, кабинет, касса.
- Мини-игры для каждого кабинета; врач автоматически лечит простые болезни, сложные остаются игроку.
- Персонал (регистратор, врач, медсестра, лаборант, уборщик) с зарплатой и постами.
- Экономика: день 180 секунд, расходы, штрафы и «кредит доверия» без game over, итоги дня.
- Задания (ежедневные, недельные, сюжетные), опыт, уровни, кристаллы, облики за монеты и кристаллы.
- Сохранение в `localStorage` (`hospitaria.iso.layout.v1`).

## Старая боковая версия: как запустить

Боковая версия v0.1 не входит в основную игру: в меню её нет. Код сохранён в `src/legacy/`
и подключается только при открытии `http://localhost:8080/?legacy=1` (динамический `import()`,
обычный запуск её не скачивает). Откроется меню v0.1 со своим сохранением `hospital_save_v1`.
Это сохранение v0.2 не меняет и не удаляет, оно же служит резервной копией для миграции.

### Перенос старого сохранения

Если изометрического игрока ещё нет, а ключ `hospital_save_v1` есть, главное меню один раз переносит:
имя, монеты, уровень и опыт, репутацию, число вылеченных. Купленная в v0.1 мебель и одежда
не переставляются (другие комнаты), вместо этого их цена возвращается монетами.
Повторно перенос не запускается и прогресс v0.2 не затирает. Код: `src/systems/migrateV1.js`.

## Структура

- `src/main.js`, `src/scenes/`: запуск и сцены v0.2 (меню, создание персонажа, больница, HUD, гардероб, мини-игра).
- `src/iso/`: изометрия (математика, сетка, сортировка глубины, мир, камера, режим строительства),
  актёры, пациенты, персонал, поиск пути, панели HUD, обучение.
- `src/systems/`: чистая игровая логика без Phaser (экономика, задания, кабинеты, сохранение, миграция).
- `src/data/`: данные и баланс (болезни, каталог, экономика, квесты, кабинеты, планировка).
- `src/minigames/`, `src/ui/`: мини-игры и UI-кит (`IsoUi.js`).
- `src/legacy/`: боковая версия v0.1. `src/debug/`: тестовые сцены (`?debug=1`).
- `assets/`: PNG (`final/`), исходники (`raw/`), `manifest.md`, `spec.json`. `tools/`: подготовка ассетов, `balance_sim.mjs`.
- `docs/`: `decisions.md` (решения), `balance.md` (отчёт баланса), `TODO_v2_stages_12_20.md`.
- `tests/`: node-тесты без браузера. Запуск: `sh tests/run_all.sh`.

Правила: файл не длиннее 300 строк, логику без Phaser выносить в чистые модули и тестировать в node.

## Работа с ассетами

Положить PNG из Higgsfield в `assets/raw/`, запустить `python3 tools/prepare_assets.py` и
`python3 tools/slice_sheets.py`, результат появится в `assets/final/`. Подробности в `assets/manifest.md`.
