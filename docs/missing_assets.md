# Каких PNG не хватает

Обновляется по ходу этапов v2. Пока ассета нет, игра использует готовый PNG или
кодовую заглушку, а не новую нарисованную картинку.

## 1. Послойная кастомизация игрока (для полной версии этапа 12)

Сейчас облик это один готовый спрайт `staff_*`. Чтобы менять лицо, причёску, одежду и
аксессуары по отдельности, нужен набор слоёв. Требования ко всем файлам:

- размер холста **224 px по высоте** (как `staff_doctor.png`), ширина с запасом под
  причёску и аксессуар;
- прозрачный фон, PNG-24/32;
- общая точка привязки: **низ по центру** (anchorX 0.5, anchorY 1.0), персонаж стоит
  на нижней кромке холста;
- масштаб 2x, как у остальных спрайтов `assets/final` (в игре `scale 0.5`);
- вид строго сбоку, вправо; влево игра отражает спрайт через `flipX`;
- одинаковое освещение и толщина контура, чтобы слои не выглядели чужими.

Отдельный файл на каждый слой:

| Файл | Что на нём | Обязательные варианты |
| --- | --- | --- |
| `layers/head_base.png` | голова и шея, нейтральное лицо | 3 оттенка кожи или тонируемая маска |
| `layers/eyes_*.png` | глаза и брови | 2-3 варианта |
| `layers/hair_*.png` | причёска | 4-6 вариантов |
| `layers/torso_doctor.png` | белый халат врача | 1 |
| `layers/torso_nurse.png` | форма медсестры | 1 |
| `layers/torso_casual_*.png` | повседневная одежда | 2-3 |
| `layers/legs_*.png` | ноги и обувь | 2-3 |
| `layers/accessory_*.png` | фонендоскоп, очки, шапочка, бейдж | 3-4 |

Порядок отрисовки: ноги -> торс -> голова -> глаза -> волосы -> аксессуар.
Код `AvatarLayers.js` (контейнер со слоями, синхронный `flipX` и покачивание) писать
только после появления этих файлов.

## 2. Иконки симптомов для пациентов

В `assets/final/icons` есть 11 иконок болезней, но для части диагнозов подходящей нет.
Не хватает файлов (192x192, прозрачный фон, тот же стиль, что `icon_fever.png`):

- `icon_ear.png` (ушная боль);
- `icon_sun.png` (солнечный ожог);
- `icon_sleep.png` (переутомление);
- `icon_sinus.png` (гайморит);
- `icon_lungs.png` (бронхит);
- `icon_food.png` (пищевое отравление);
- `icon_water.png` (обезвоживание);
- `icon_bandage.png` (растяжение);
- `icon_bug.png` (укус насекомого);
- `icon_pill.png` (нехватка витаминов).

Пока они не готовы, `src/data/actorConfig.js` использует ближайшие существующие иконки.
