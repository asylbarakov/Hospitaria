# ART.md: стиль-гайд Hospitaria (изометрия)

Единый стиль важнее детализации. Если ассет выбивается из стиля, его лучше перегенерировать, чем «чинить» в игре.

## 1. Геометрия (жёсткие числа, код на них опирается)

| Параметр | Значение |
|---|---|
| Проекция | изометрия 2:1 (dimetric), камера сверху-справа, как в Two Point Hospital |
| Размер тайла | **128 × 64 px** (ромб: ширина 128, высота 64) |
| Формула | `x_screen = (x − y) · 64`, `y_screen = (x + y) · 32` |
| Высота стены | 192 px (3 тайла по вертикали ромба) |
| Высота персонажа | около 100-110 px в игре (чуть меньше стены) |
| Точка опоры (anchor) | низ-центр ромба-основания предмета: `(0.5, y_нижней_вершины / высота)`, записывается в `assets/manifest.md` |
| Свет | сверху-слева, тени падают вправо-вниз, мягкие, прозрачность 20-25% |
| Стиль | **глянцевый мягкий 3D («clay», как иконки в мобильных играх)**, эталон: кровать из этапа 9, скруглённые формы, перламутрово-белый + мятно-бирюзовый, без контурной обводки |
| Фон | параметр `background: transparent` у `gpt_image_2_6`; если фон не прозрачный, запасной путь: цельный **ярко-зелёный #00FF00** + `tools/prepare_assets.py` (на белом фоне автовырезание не работает: белые простыни сливаются с фоном) |

## 2. Палитра

Основа взята из текущей игры, чтобы меню и HUD не выбивались.

| Роль | HEX |
|---|---|
| Белый халат / стены | #F7FBFD |
| Холодный голубой (акцент больницы) | #3F8FB0 |
| Светло-голубой (стекло, вода) | #8FD3F4 |
| Мятно-зелёный (аптека, успех) | #4CAF50 |
| Красный крест / тревога | #E53935 |
| Тёплый жёлтый (свет, монеты) | #FFD54F |
| Дерево / пол | #E4D8BF |
| Тёмно-синий (текст, тени) | #1B4B5A |
| Металл | #90A4AE |
| Розовый (палата, педиатрия) | #F48FB1 |

Правило: не больше 3 акцентных цветов на предмет, остальное нейтральное.

## 3. Референсы (держать в каждом запросе)

- [ ] Аватария: пропорции персонажей (крупная голова, мягкие формы)
- [ ] Two Point Hospital: угол камеры, читаемость оборудования
- [ ] Hay Day: мультяшная мягкость, чистые цвета

Загрузить 2-3 картинки как reference в Higgsfield (если модель принимает `medias`). После первого удачного ассета использовать **его** как главный референс: «same style as reference».

## 4. Общий префикс промпта (вставлять в начало каждого запроса)

```
Isometric 2:1 dimetric game asset in glossy soft 3D clay style, like a premium
mobile game icon: smooth rounded shapes, pearly white and soft mint-teal
materials, gentle top-left lighting, tiny soft contact shadow under the object
only, single object centered with a small margin, fully visible, no text,
no watermark. Object: ...
```

Параметры генерации: `model: gpt_image_2_6`, `aspect_ratio: 1:1`, `resolution: 1k` (для крупных предметов 2k), `quality: medium`, `background: transparent`.

Не надо: realistic photo, harsh black outlines, perspective view, side view, top-down view, cropped object, checkerboard background.

## 5. Как держать единый стиль

1. Сначала сделать **эталонный кадр**: один предмет (например, кровать) и один персонаж. Утвердить.
2. Все следующие запросы идут с эталоном как reference и фразой `same style, same palette and proportions as reference`.
3. Предметы одной комнаты генерировать подряд в одной сессии.
4. Мелкие иконки и UI делать **листом 4×3 на одной картинке**, потом нарезать: быстрее и ровнее по стилю.
5. Не тратить время на идеальный ракурс: небольшой перекос поправляется масштабом и якорем. Проверка: наложить спрайт на ромб 128×64 (шаблон: см. шаг ниже).

## 6. Проверка ракурса за 1 минуту

Нарисуйте (или найдите) ромб 128×64 и положите спрайт «в основание». Нижние рёбра предмета должны идти по рёбрам ромба под углом около 26,6° (это и есть 2:1). Если рёбра круче или площе, перегенерируйте с фразой `exact 2:1 isometric, 30 degree camera`.

## 7. Модели Higgsfield (по результатам проверки аккаунта)

| Задача | Модель | Почему |
|---|---|---|
| Мебель, комнаты, декор, иконки, UI | `gpt_image_2_6` | поддерживает `background: transparent`. Цена 0,25 кредита за картинку (1k, low/medium). **Безлимитная квота** (free-trial unlim) покрывает 1k/2k и low/medium **до 14.11.2026 ~06:56 UTC**, принимает **по одной генерации за раз** (параллельные запросы отклоняются с 429) |
| Эскизы персонажей | `soul_2` (unlim) или `gpt_image_2` | персонаж в нейтральной позе T/A для анимации |
| Спрайт-листы персонажей | `autosprite` (AutoSprite Animation) | делает изометрические листы по одной картинке: пресеты `iso_idle_*`, `iso_walk_*` |
| 3D-модели (не нужны) | `image_to_3d` и др. | в плане не используются |

**Кредитов на аккаунте сейчас 10.** Перед любым платным действием смотрите цену в интерфейсе. Порядок трат: сначала всё на unlim-моделях, AutoSprite только для утверждённых персонажей.

## 8. Выходные требования к файлам

- Формат: PNG (после сжатия PNG-8 или WebP), общий вес `assets/` меньше **8 МБ**.
- Имена: `snake_case`, без пробелов и кириллицы (`reception_desk.png`).
- Обрезка: поля не больше 4 px, якорь записан в `manifest.md`.
- Персонажи: кадр 128×128 (в 2 раза меньше исходных 256, если качество позволяет).
- Всё складывается в `assets/raw/` (как есть из Higgsfield), а готовое в `assets/final/`. Атласы позже в `assets/atlas/`.
